# Task Manager Application

## 📌 Description
A full-stack Task Manager app built using FastAPI (backend) and React.js (frontend). Users can create projects, add tasks, and view analytics of completed and pending tasks.

---

## 🚀 Tech Stack
- Backend: FastAPI, SQLAlchemy, SQLite
- Frontend: React.js
- Authentication: JWT
- Charts: Chart.js

---

## ⚙️ Setup Instructions

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend
```bash
cd task-frontend
npm install
npm start
```

---

## 📊 Features
- Create Projects
- Add Tasks
- Task Analytics (Completed / Pending)
- JWT Authentication
